# Stain Crates 🎁

**Minecraft Plugin – Stain Crates**  

A simple and fun Minecraft plugin that allows server admins to create and manage crates with rewards. Perfect for survival, mini-games, and RPG servers.

---

## 🌟 Features | Tính năng

- `/staincrates` – Main command to open the plugin menu.  
- Add, remove, and manage crates.  
- Reward players with items, money, or custom loot.  
- Fully configurable in the plugin config files.  
- Lightweight and easy to use.

**VI:**  
- `/staincrates` – Lệnh chính để mở menu plugin.  
- Thêm, xóa và quản lý crates.  
- Thưởng người chơi bằng item, tiền, hoặc loot tùy chỉnh.  
- Hoàn toàn cấu hình được trong file config.  
- Nhẹ, dễ sử dụng.

---

## ⚙️ Installation | Cài đặt

1. Download the latest release `.jar` from the [Releases](https://github.com/yourusername/staincrates/releases).  
2. Place the `.jar` file into your server's `plugins` folder.  
3. Start or restart your Minecraft server.  
4. Configure crates in `plugins/StainCrates/config.yml` as needed.

**VI:**  
1. Tải bản `.jar` mới nhất từ [Releases](https://github.com/yourusername/staincrates/releases).  
2. Đặt file `.jar` vào thư mục `plugins` của server.  
3. Khởi động lại server Minecraft.  
4. Cấu hình crates trong `plugins/StainCrates/config.yml` theo ý muốn.
